# 🛒 Protótipo do Mercado Livre

Recriação do **cabeçalho do Mercado Livre** com HTML e CSS, feita como atividade individual de Front-End.

## ✨ O que tem

- 🏷️ Logo e campo de busca com ícone de lupa
- 📍 Atalho "Informe o seu CEP"
- 🧭 Menu com Categorias, Ofertas do dia, Histórico e Vender

## 🛠️ Tecnologias

HTML · CSS

## 🚀 Como executar

Baixe o repositório e abra `Católica/index.html` no navegador.
